How we measure

3-year leakage-safe backtest
The charts below show what the model would have predicted if you had asked it every day for the past ~3 years — using only information available at that moment. Four invariants make this honest:
1 · Walk-forward
36 retraining rounds, each producing 30 days of fresh predictions on data the model has never seen. No peeking at the future.
2 · Purged
Training rows whose target window overlaps the test fold are dropped. A 30-day forecast made on day T cannot learn from day T+5's actual move.
3 · Embargoed
Extra gap days between train and test (half the horizon) prevent leakage via autocorrelation — overnight price moves bleeding into the "training" window.
4 · Per-fold feature selection
Features are re-ranked on every fold using training-only rows. We never pick features that happen to work because they saw the test answer.
All four invariants have pytest tests that fail-the-build if violated · source on GitHub · see tests/phase0/test_leakage_audit.py
