# 전 기간 가격 백테스트와 차트 갱신

2026-09-05. 최우수 모델을 과거 전체에 그리려는 요청에 따라, 월별 재학습과 원본 발행 기록을 구분하는 역사 재검증을 추가한다.

## 평가 범위와 고정 선택

저장된 36-fold 장기평가를 먼저 재사용해 후보군을 정했다. 7일·30일 모두 무변화 기준이 최저 가격 오차였다. 학습형 단일 모형 중 수익률 MAE 상위 ExtraTrees, 운영 구성 RF/KNN, RF+KNN 동일 가중 조합, 고정 Ridge/HGB 가격/HGB 가격+흐름을 무변화와 비교한다. **이번 여덟 후보 내 최우수**라는 뜻이며 가능한 모든 모델 중 최고라고 주장하지 않는다. 기존 RF+KNN 운영의 추가 보정·선택 가중까지 동일하게 복원한 실전 정책이라는 뜻도 아니다.

기존 CatBoost는 최근 한 달 재학습 측정에서 7일 51.15초, 30일 47.07초가 걸렸다. ExtraTrees 0.34~0.36초, RF 0.60~0.65초, KNN 약 0.03초였다. 모든 하위 모델과 방향 분류기를 전 기간 다시 탐색하지 않는다. 가격오차 상위 후보와 새 흐름 효과를 먼저 비교한다. 확률 보정, 과거 주문 체결, 투자 수익률 백테스트는 이 가격 차트 작업의 성과로 표시하지 않는다.

- 소스 전체는 종료된 UTC 일봉이다. 일봉 시작일+1일을 기준시각으로 사용한다. 초기 500개 이상의 학습행과 purge/embargo를 확보한 최초 달부터 최신 만기까지 가능한 모든 날짜를 평가한다. 초기 학습 구간을 예측 성공 구간으로 채우지 않는다.
- 7일은 3년, 30일은 5년 학습창이며 달 초에 재학습한다. 학습 목표일은 달 초보다 각각 3일/15일 이전이어야 한다. 특징 커버리지·상관·선택과 시간 감쇠 가중치는 해당 학습 구간에서만 계산한다.
- 공급자 업데이트 간격의 추정도 해당 달 학습시각 전에 고정한다. 다만 과거 거시·온체인 공급자의 당시 공개본을 복원하지 못했으므로 **수정된 역사 자료를 사용하는 재구성 백테스트**다. 거래 흐름 역사도 당시 다운로드 시각이 알려진 실전 기록은 아니다.
- 개별 월 예측을 캐시한다. 코드·프로토콜·라이브러리와 해당 시점까지의 가격/흐름 입력 hash가 같으면 재사용한다. 실제값은 따로 대조하므로 미래에 만기나 실제값 정정이 생겼다고 옛 모델을 불필요하게 다시 적합하지 않는다. 훈련이나 예측에 영향을 주는 입력 정정은 해당 캐시를 무효화한다.

## 두 종류의 최고 모델

1. **전 기간 최우수 고정 모형:** 동일 날짜의 수익률 MAE가 가장 작은 후보. 각 월의 학습은 시간순으로 분리하지만 ‘전체 평가에서 우승했다’는 선택은 사후 판단이다. 실전 재현 성능과 혼동하지 않도록 차트에 retrospective로 표시한다.
2. **과거 성과로만 선택하는 경로:** 매월 그 시점에 만기가 끝난 이전 365일의 OOF 오차로 모델을 고른다. 최소 90개의 평가 날짜가 없으면 무변화를 사용하고, 동률이면 무변화를 우선한다. 미래 수익률을 바꿔도 이전 선택이 달라지지 않는 검사를 포함한다.

동일 기간으로 맞춘 MAE/RMSE, 무변화 대비 개선율, UP/FLAT/DOWN 전체 정확도와 급등·급락 recall을 저장한다. 마지막 두 수치는 점예측을 발행시점 변동성 임계값으로 분류한 결과이며 기존 조건부 방향 분류기의 보정 확률 성과가 아니다. 전체·최근 365일·연도별로 분리하고, 최우수/선택 경로의 MAE 차이에 최소 30일 달력 블록으로 1,000회 구간을 계산한다. 이는 사후 모델 선택·반복 실험 편향을 제거한 승격 검정이 아니다. 후보군도 이전 평가를 참고해 정했으므로 독립 전진 검증은 계속 필요하다.

## 배포·자동 갱신

7일/30일 작업은 동일한 입력 snapshot을 받아 별도 실행한다. 만기당 25분 계산 예산과 30분 job 제한이 있다. 실패해도 완료된 월별 캐시는 별도 브랜치에 남기고, 두 만기가 모두 완료·일치해야 새 차트를 발행한다. 매주 일요일 UTC 07:13 / 한국시간 16:13 재검증하고, 동일한 과거 구간은 캐시를 재사용한다.

`data/full-backtest`에 계산 근거·월별 checkpoint·원시 예측을 보관한다. 홈페이지에는 `full_backtest.json`, 원시 예측 다운로드, index.html만 배포한다. 실제 발행 DB와 live history, 운영 모델 번들은 그대로 보존한다. 페이지에는 전체/최근/연도 선택, 모델 선택, 가격/수익률 전환을 제공한다. 현재 최우수 모델이 무변화라면 그대로 표시한다.

검증: `python -m pytest tests -q`. 미래 결과로 과거 모델 선택 변경 방지, vendor 간격 추정 고정, 학습 purge/embargo, 중복·상이한 날짜 집단 거부, 월별 캐시와 실제값 분리, 입력 정정 시 재적합, 실모형 한 달 실행 및 UTC/서울 차트 값 검사를 포함한다. 실제 전체 기간과 최종 순위·계산 시간은 배포된 보고서에서 확인한다.
